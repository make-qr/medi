## 3. Phong cách viết (chuẩn Omegle blog)

Áp dụng `HUONG-DAN-VIET-BAI-BLOG.md` + giọng bài mẫu *Why Older Adults Talk Less*:

| Tiêu chí | Yêu cầu medi |
|----------|--------------|
| Độ dài | ≥ 1.000–1.500 từ EN |
| Giọng | Ấm, chậm, kể chuyện → insight; không bullet encyclopedia kiểu MNT |
| Heading | ≥ 3 `##` + TOC |
| Ảnh | Hero + ≥1 inline (Unsplash, localize) |
| CTA | **1** box cuối (hoặc mid nếu loneliness night) → chat |
| Disclaimer | Cuối mọi bài: *not medical advice* |
| Nguồn | Tóm tắt nghiên cứu công khai (CDC, NIA, WHO, peer-review) — **không** copy đoạn MNT |
| Cấm | Chẩn đoán, liều thuốc, “cure”, fear-mongering |

**Công thức bài medi:**

```
[Cảnh đời thường: đêm dài / im lặng / ăn một mình]
        +
[Ý khoa nhẹ: loneliness / sleep / stress / brain — 1–2 insight]
        +
[Cầu nối: nói chuyện, solitude vs loneliness, an toàn]
        +
[CTA mềm + disclaimer]
```
